## 🚀 GitHub Pages 배포 및 업데이트 가이드

### 방법 1: 터미널에서 Git으로 간편하게 푸시하기 (권장)

저장소가 아직 로컬에 연결되지 않은 경우, 터미널(PowerShell 또는 Git Bash)에서 아래 명령어만 순서대로 실행하시면 됩니다:

```bash
# 1. 깃 브랜치를 main으로 설정
git branch -M main

# 2. 본인의 GitHub 저장소 주소 연결 (아이디와 저장소명을 입력하세요)
git remote add origin https://github.com/[사용자아이디]/[저장소이름].git

# 3. 변경사항 푸시
git push -u origin main --force
```

---

### 방법 2: GitHub 웹사이트(github.com)에서 직접 업로드하기

1. 본인의 GitHub 저장소 페이지에 접속합니다.
2. 상단 메뉴의 **[Add file]** ➔ **[Upload files]**를 클릭합니다.
3. 이 폴더의 **`index.html`** 파일(단일 통합본)을 드래그하여 업로드 영역에 끌어다 놓습니다.
   *(필요한 경우 `README.md`도 함께 올립니다)*
4. 하단의 녹색 **[Commit changes]** 버튼을 클릭합니다.

## ⚠️ "업로드했는데 사이트에 변화가 없어요!" 해결 방법

GitHub Pages 사이트에서 새로 고침해도 이전 화면이 그대로 보인다면 **다음 2가지 원인** 때문입니다:

### 1. GitHub Pages 빌드 대기 시간 (약 1~2분 소요)
- GitHub에 파일을 커밋하면 자동으로 배포 빌드(GitHub Actions)가 실행됩니다.
- 저장소 상단의 **[Actions]** 탭에 들어가셔서 노란색 불이 **초록색 체크(✔)**로 바뀔 때까지 1분 정도 기다려 주세요.

### 2. 브라우저 캐시(Cache) 강력 새로고침 필수!
- 브라우저는 이전에 방문한 사이트의 CSS/JS를 컴퓨터에 임시 저장(캐시)해 둡니다.
- 배포 사이트 주소에 접속하신 후 키보드로 **강력 새로고침**을 눌러주세요:
  - **Windows (Chrome / Edge / Whale)**: `Ctrl + F5` 또는 `Ctrl + Shift + R`
  - **Mac (Safari / Chrome)**: `Cmd + Shift + R`
- 또는 **시크릿 모드(InPrivate / Incognito 창)**에서 접속하시면 즉시 최신 버전으로 확인하실 수 있습니다.
